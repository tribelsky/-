# ARGUS-10 | מעבדת בדיקה מקבילה (גרסת מחקר 0.1)

ניסוי קריאה בלבד בעשרה מאגרי GitHub ציבוריים, על ענף נפרד של Transformix, ללא שינוי אפליקציות המקור.

## מה המערכת עושה בפועל
- מפעילה עד עשר עבודות GitHub Actions במקביל, אחת לכל מאגר.
- קוראת רק קובצי מקור מוגדרים מראש, מתוך מזהי commit נעולים.
- מזהה סימני קוד ממוקדים ומפיקה לכל מקור טביעת SHA-256 וקישור למקור.
- בשני מקרים מריצה שחזור פונקציה מבודד: Langflow/CP1252, AnythingLLM/variable-expansion.
- שומרת עשרה קובצי JSON נפרדים ומסכמת אותם לדוח Markdown + JSON.
- בוחרת כלי בדיקה והצעת טיפול שונים לכל אחת מעשר האפליקציות.

## מה המערכת לא עושה
- אינה מתקנת מאגר חיצוני, מתקינה תוכנה של צד שלישי או מפעילה שירותים מרוחקים.
- אינה מריצה מבחני קבלה מקצה לקצה על האפליקציות.
- אינה מוכיחה שכל דיווח GitHub Issue הוא תקלה פעילה.
- אינה פותחת Pull Requests או מעבירה מידע לצדדים שלישיים.

## קבצים
- `targets.json`: עשרת המאגרים, commit מלא, קובצי בדיקה, מקור הדיווח והכלי המומלץ.
- `probe.py`: סורק ממוקד, קריאה בלבד, מגבלת 400KB לקובץ וזמן 20 שניות.
- `probe_anything.cjs`: שחזור מבודד של פונקציית החלפת המשתנים מתוך קוד מקור קבוע.
- `aggregate.py`: איחוד הדוחות ושמירת הגבולות בין ראיה למסקנה.
- `.github/workflows/argus-ten-probe.yml`: עשר עבודות מטריצה עצמאיות.

## איך לקרוא תוצאות
`source_anchor_found` אומר רק שהמקטע מופיע בקוד שנבדק.
`mismatch_reproduced` אומר ששוחזרה התנהגות חריגה בפונקציה מבודדת עם תנאים מבוקרים.
תיקון הוכח רק כאשר מבחן אינטגרציה נכשל לפני שינוי ועובר אחרי שינוי בעותק מבודד; לא נעשה בניסוי זה.
